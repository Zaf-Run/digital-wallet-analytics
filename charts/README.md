# Chart notes

These charts are embedded in the main README using relative paths.

- `transaction_volume_by_type.png` uses the rounded transaction-count shares reported in the README.
- `transaction_value_share.png` shows the reported 42% TRANSFER and 2.5% PAYMENT shares; the remaining 55.5% is grouped as other types.
- `fraud_label_share.png` uses the reported 8,213 fraud-labeled transactions, approximately 0.13% of total volume.
- `modeled_net_revenue_share.png` uses the reported 62% CASH_OUT, 33% TRANSFER, and 5% PAYMENT split.

PaySim is simulated data. Revenue shares are scenario estimates based on assumed fee rates, not actual provider revenue. Values are rounded as reported in the project README.
